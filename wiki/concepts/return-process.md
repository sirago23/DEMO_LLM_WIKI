# Return Process (RMA)

How to initiate an exchange or return with Seattle Coffee Gear.

## RMA requirement

An RMA (Return Merchandise Authorization) number is required before any return or exchange will be accepted. Do not ship items back without one.

## Steps

1. Email support@seattlecoffeegear.com with your order number
2. Describe why you want to return — SCG will suggest an exchange if a better-fit product exists
3. SCG sends an RMA email with detailed return/exchange instructions
4. Ship the item back following the RMA instructions

**Have your order number ready** — it is required to process the return.

## Miele machines

Contact Miele directly at **1-800-999-1360** for return authorization before requesting an RMA from SCG.

## Retail store returns

Retail purchases must be returned or exchanged at the **specific store where purchased** — cross-location returns are not accepted. The store will assess the item and issue a refund on-site where possible; complex assessments may be escalated to the returns manager with follow-up provided.

## Condition requirement

All machines and electric appliances must arrive back in [[concepts/like-new-condition]]. Equipment not meeting this standard will be assessed for damage and may incur refurbishment fees.
